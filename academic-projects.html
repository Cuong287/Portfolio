Project context

01Define the system

Set the structural scheme and preliminary member dimensions using geometry, spans, load transfer, and constructability.

02Determine actions

Calculate permanent and imposed loads, convert slab loads to equivalent frame loads, and assess wind actions for Da Nang.

03Model and analyse

Build the ETABS frame, assign sections and loading cases, then review gravity and lateral response.

04Design members

Use governing internal-force combinations to design main beams and columns and select reinforcement.
